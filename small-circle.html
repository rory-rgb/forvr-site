HOW IT WORKS.

One lighting setup, held for the entire collection. Keeping the light fixed is what makes a set stack: every piece, every pose, every crop sits in the same world, so the collection reads as one shoot rather than a folder of separate pictures.

Shot in a single sitting against one concrete sweep, with the ball as the only prop that moves. Editorial framing throughout, so the garments carry the frame instead of being laid out flat for a catalogue.

Eighteen frames here. The rest sit in the archive.
